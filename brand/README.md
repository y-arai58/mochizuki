# 望月 ｜ ロゴ

満月＝ただの円になり識別できないため、マークは**満ちる途中の月**（`f = 0.72`／十一日月あたり）を描いています。名前が到達点、マークがその過程を表しています。

マークは本体と同じ `litPath()`（`src/lib/moon.ts`）で描かれています。月相の定義を変えるとロゴも一緒に変わります。画面上のロゴは `src/components/Mark.tsx` を使ってください。

## ファイル

| ファイル | 用途 |
|---|---|
| `mark.svg` | 主マーク。24px以上 |
| `mark-small.svg` | 16〜32px。輪郭線を省いた版 |
| `mark-ring.svg` | 目盛りの環つき。64px以上の署名的な使い方に限る |
| `mark-mono.svg` | 単色（1色印刷・淡い地） |
| `mark-reverse.svg` | 反転（濃い地） |
| `logo-horizontal.svg` | 横組みロックアップ |
| `logo-stacked.svg` | 縦組みロックアップ |
| `icon.svg` | アプリアイコン 512 |
| `icon-maskable.svg` | maskable用（セーフエリア内に縮小） |
| `favicon.svg` | 32px相当 |

書き出したPNG（`icon-192` `icon-512` `icon-maskable-512` `apple-touch-icon` `favicon-32`）は `public/` にあります。

## 色

| 役割 | 色 |
|---|---|
| 影の側 | Slate Blue `#54677A` |
| 光の側 | Moon Lit `#F7F0DE` |
| 輪郭 | Charcoal `#2F3439` opacity .5 |
| 地 | Warm Ivory `#F2EEE6` |
| 目盛り | Pale Gold `#E3C489` |

光の側 `#F7F0DE` は地の `#F2EEE6` とごく近い色です。これは意図した設計で、月が背景に溶けて影の側だけが際立ちます。**白地に置く場合も地はアイボリーのまま**にしてください。純白の上に置くと光の側が浮いて見えます。

## 決まりごと

- **最小サイズは16px。** それ以下では使わず、環つき版は64px未満で使わない
- **余白は月の直径の1/4以上。** ロックアップでは文字までの距離もこれに準じる
- 回転させない。月の欠ける向き（右が明るい）は満ちる方向を示しているため、反転も不可
- 影の側を黒、光の側を純白にしない。低彩度の指定色を使う
- 影を落とさない、角丸の枠に入れない、グラデーションをかけない
- ロックアップの「望月」は明朝、「MOCHIZUKI」はサンセリフに `letter-spacing` 広め。組み替えない

## フォントについて

`logo-horizontal.svg` と `logo-stacked.svg` の文字はフォント指定のままです。閲覧環境に明朝が無いと別の書体で表示されます。印刷物や外部配布に使う場合は、使用する明朝体を決めて**文字をアウトライン化**してください。画面上ではOS標準の明朝にフォールバックさせる前提で問題ありません。
